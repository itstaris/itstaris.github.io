# Game Landing Page

Site estático (HTML, CSS e JS puros), pronto para o GitHub Pages.

## Estrutura
- `index.html` — conteúdo. Procure por **TROCAR** para achar textos, imagens e links a preencher.
- `css/style.css` — estilos (fontes, cores e texturas ficam no topo do arquivo).
- `js/script.js` — menu, rolagem e animações.
- `assets/` — coloque aqui imagens, logo e PDFs.

## Trocar um placeholder de imagem
Substitua o bloco `<div class="media ph">…</div>` por:
`<img class="media" src="assets/arquivo.jpg" alt="Descrição da imagem">`

## Publicar no GitHub Pages
1. Envie esta pasta para um repositório no GitHub (`index.html` na raiz).
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará em `https://seu-usuario.github.io/nome-do-repositorio/`.
